# anythihng2ynab

## Short explanation 
This is a data pump (and a framework) for reading data from *any sources* 
and input the data into YNAB using their APIs.

The program can be run either locally, or using a cloud provider like 
[Heroku](https://www.heroku.com). The software is in fact primarily written
to be run on Heroku, but adding the ability to run it locally was really
easy. This also means that it can be set up to run on any kind of machine.


## Currently supported source
